# Melody Challenger 小规模试用前收尾日志

## 目标与边界

- 不建设大规模运营系统。
- 完成密码安全处置、可恢复备份、PWA 更新体验和高风险 Hook 闭包修复。
- 修复后部署生产，随后停止继续加功能，进入 5–10 人试用。

## 基线

- 分支：`codex/pre-pilot-hardening`。
- 起点：`1fd4dd2`。
- 生产版本：v3.3.0；Supabase RPC 与 RLS 已硬化。
- 已知 21 条 Hook 依赖 warning。

## 根因记录

- PWA 使用 `autoUpdate`，新 Service Worker 激活后不会主动刷新已打开页面；导航页又被缓存 1 天，用户可能长期运行旧 bundle。
- Hook warning 需要按运行风险分类，只处理会捕获旧闭包、重复订阅、计时器泄漏或资源未释放的项。
- 曾暴露的测试密码无法通过仓库操作轮换，必须在 Supabase Auth 管理端重置；仓库侧需确认无明文残留。

## 验收门槛

- 新版本可提示更新并由用户确认刷新。
- 数据库结构、课程内容和必要进度表有本地备份，且提供恢复顺序与校验命令。
- 高风险 Hook warning 清零或有明确证据判定为低风险。
- 构建、测试、生产依赖审计、浏览器烟测和生产部署通过。

## 实施结果

- Supabase 控制台已接受测试账号密码恢复邮件请求；旧密码需在邮箱内完成重置后才会失效。
- Supabase 平台显示每日自动备份；仓库新增不含用户数据的公开内容快照和恢复手册。
- 公开快照：12 技能、51 课程、24 等级、30 成就，SHA-256 `3aae6edb9c716634cca7a14edb0575d5c2056c96841bc82275bd2c1ac2417cc2`。
- PWA 改为 `prompt` 更新，并增加“更新并刷新/暂不更新”提示。
- 高风险 Hook warning 已清理，warning 总数由 21 降至 10；剩余均为一次性读取函数定义形式。
- 新增统一延迟回调清理 Hook，页面卸载时取消待执行切关、反馈、音频和登录提示。
