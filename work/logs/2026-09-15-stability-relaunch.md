# Melody Challenger 稳定性重启日志

## 目标

在保留现有产品资产和技术栈的前提下，提高核心训练链路的稳定性、可测试性、安全性和加载性能，并完成生产部署。

## 授权与边界

- 用户已授权直接重构并部署到线上。
- 当前没有活跃用户，可进行兼容性良好的结构调整。
- 分支：`codex/stability-relaunch`。
- 回滚基线：`master` / `3e00445d8d4685d9cd8f8f482728e8967f3e6e90`。
- 数据库变更仅采用向前兼容迁移；高风险或无法验证的迁移不直接执行。

## 实施计划

1. 安全止血：移除仓库中的明文测试凭据，环境化后端配置，修复生产依赖漏洞。
2. 质量底座：加入单元测试、覆盖率、CI 与可复现环境说明。
3. 核心稳定性：修正认证初始化、游客数据同步、音频生命周期、异步竞态和错误反馈。
4. 渐进重构：提取超时、数据访问和领域算法；减少页面对 Supabase 的直接耦合。
5. 性能体验：路由懒加载、拆包、错误边界、加载态和离线策略收口。
6. 验证部署：构建、Lint、测试、依赖审计、浏览器核心路径、生产部署及线上烟测。

## 实施记录

- 依赖升级并精确锁定兼容版本；生产依赖漏洞从 3 high 降至 0。
- 增加 Vitest、覆盖率配置和 GitHub Actions；音高检测与间隔复习共 17 项测试通过。
- 认证初始化改为幂等，登录后先同步 Zustand 用户状态再迁移游客数据；失败同步保留本地记录。
- 重写麦克风/音高 Hook：明确媒体流状态、约 30 Hz 分析、权限错误、10 秒超时、卸载释放与迟到流清理。
- 修复听音、哼唱每小题/关卡错误增加 `total_games` 的计分问题。
- 增加应用错误边界、路由懒加载和 vendor 拆包；最大应用包由 830.83 kB 降到约 266 kB。
- 移除首屏音频采样预加载；Supabase 请求不再由 Service Worker 自动重放。
- Supabase 从当前执行环境被代理以 503/连接关闭阻断，无法验证真实后端状态；增加后端不可用时的游客核心练习兜底。
- 浏览器验证：游客引导跳过、学习中心兜底、练习场、听音配置、375px 无横向溢出、麦克风拒绝错误提示均通过。
- 移除仓库内明文测试登录凭据；账号密码仍需要由所有者在外部系统轮换。
